  \section{Introduction}
  Automated valuation models (AVMs) are used for mortgage decisions, market transparency, and risk management. But raw listings from \texttt{bina.az} are tricky to work with. Prices go from 11 AZN up to 627,130 AZN, the descriptions are written in free-form Azerbaijani with inconsistent wording, and many categories are very imbalanced.

  In this project we wanted to show that models we code ourselves from the basic math can give results close to professional libraries. Our main contributions are:
  \begin{itemize}
    \item \textbf{From-scratch algorithms}: A recursive binary decision tree (MSE, Gini, and entropy) and a hinge-loss SVM trained with Pegasos, using Random Fourier Features to get non-linear decision boundaries. Both are vectorised with NumPy.
    \item \textbf{Leakage-free features}: Careful data cleaning, extracting information from the text, frequency encoding, and computing every statistic only on the training data.
    \item \textbf{Benchmarking}: We compare against scikit-learn on 93,150 samples, with 5-fold cross-validation, residual analysis, and hyperparameter sweeps.
    \item \textbf{Reproducibility}: One command (\texttt{python -m src.run\_all}) recreates all 19 figures and tables.
  \end{itemize}

  \section{Related Work / Background}
  Decision trees split the feature space with simple yes/no rules, choosing the split that makes the groups as pure as possible~\cite{breiman1984}. They are greedy, but they handle mixed numeric and categorical features, non-linear patterns, and different feature scales without needing standardization.

  A soft-margin SVM looks for the hyperplane with the widest margin while allowing a few violations (the hinge loss). Instead of solving the usual dual problem with SMO, Shalev-Shwartz et al.~\cite{pegasos} introduced Pegasos, which works directly on the primal objective with stochastic sub-gradient steps. It reaches an $\epsilon$-accurate solution in $\mathcal{O}(1/(\lambda\epsilon))$ iterations, no matter how large the dataset is. To capture non-linear patterns in the market, we map features with Random Fourier Features~\cite{rahimi2007}, which approximate the Gaussian RBF kernel $\mathcal{K}(\mathbf{x}, \mathbf{z}) = \exp(-\gamma \|\mathbf{x} - \mathbf{z}\|^2)$.

  \section{Data and Preprocessing}
  \subsection{Dataset Cleaning and Currency Handling}
  The raw dataset contains 100,775 listings scraped from \texttt{bina.az}. We handled and cleaned it through the following protocol:
  \begin{enumerate}
    \item \textbf{Currency uniformity}: Across all 100,775 records, listing currency is 100\% uniform in Azerbaijani Manat (AZN) in both scraping fields (\texttt{currency\_x} and \texttt{currency\_y}). Because no foreign-currency listings (e.g., USD, EUR) exist in the corpus, foreign exchange conversion was unnecessary, and the invariant currency columns were dropped as zero-variance features. All prices throughout this paper are denominated in AZN.
    \item \textbf{Duplicate resolution}: Listings with identical physical specifications but different timestamps were grouped, and their prices were averaged. This reduced the raw count from 100,775 to 100,773 records.
    \item \textbf{Feature extraction}: Regular expressions extracted structured room counts and renovation status (\textit{təmir}: \textit{var} vs \textit{yoxdur}) from free-text descriptions and attribute tags. Missing room counts were imputed using a 3-nearest-neighbors median over living area within the same property category, using training data only.
    \item \textbf{Target transformation}: The raw price distribution is right-skewed (skewness $0.877$, spanning 11 to 627,130 AZN). We apply the logarithmic transform $y = \log(1 + \text{price})$, stabilizing the variance and compressing extreme scales (skewness becomes $-1.340$, Fig.~\ref{fig:price_dist}).
    \item \textbf{Removal of leakage columns}: We dropped 32 unused columns to enforce strict data hygiene:
    (a)~\textit{Direct target leakage}: \texttt{unit\_price} ($\text{price}/\text{area}$) and \texttt{total\_price} (redundant target), which trivially expose the label;
    (b)~\textit{Administrative IDs and URLs}: \texttt{id\_x}, \texttt{id\_y}, \texttt{estate\_id}, \texttt{estate\_details\_id\_x/y}, \texttt{rel\_url}, \texttt{estate\_rel\_url\_x/y}, and \texttt{img\_url};
    (c)~\textit{Scraping timestamps}: \texttt{datetime\_scrape\_x/y}, \texttt{day\_x/y}, \texttt{hour\_x/y}, \texttt{city\_when}, and \texttt{updated};
    (d)~\textit{Post-hoc promotional flags}: \texttt{vip}, \texttt{featured}, and \texttt{products\_label} (commercial promotion tiers bought by sellers that artificially correlate with listing rank); and
    (e)~\textit{Unstructured text and seller titles}: raw text fields (\texttt{attributes}, \texttt{description}, \texttt{extra\_info}, \texttt{Binanın növü}) and seller titles (\texttt{owner\_name}, \texttt{shop\_name}, \texttt{owner\_title}, \texttt{shop\_title}) after regex parsing.
    All feature scalers, frequency encodings (for high-cardinality \texttt{location} and \texttt{address}), and imputation parameters were fitted exclusively on the training split.
  \end{enumerate}

  \subsection{Outlier Handling Rule}
  Outlier filtering is based on the Tukey Interquartile Range (IQR) rule: $[Q_1 - 1.5 \times \text{IQR}, Q_3 + 1.5 \times \text{IQR}]$ applied to positive values ($> 0$) of \texttt{price}, living \texttt{area}, and \texttt{land\_area}.
  
  Crucially, outlier thresholds were fitted \textbf{strictly on the training split} to prevent look-ahead bias. Trimming was applied exclusively to the training set (\texttt{apply\_bounds=True}), removing non-physical anomalies (such as 11 AZN listings and corrupted land dimensions) that would destabilize gradient descent and tree split criteria. In contrast, for validation and test splits, \texttt{apply\_bounds=False} was enforced: only missing values were dropped, while genuine luxury properties were retained. This ensures that validation and test benchmarks reflect uncurated, real-world market distributions without survivorship bias. After filtering, 93,150 clean analytical rows with 28 features remained (Table~\ref{tab:data}).

  \subsection{Data Splitting and Tier Balance Rationale}
  We partitioned the data deterministically into 67.5\% train (62,922), 16.2\% validation (15,114), and 16.2\% test (15,114) splits with a fixed seed ($\text{seed}=42$).
  
  \textbf{Stratification rationale}: To guarantee identical target distributions across splits for Task A regression, the split was stratified across 4 quantile bins of continuous \texttt{price} (\texttt{pd.qcut(y, q=4)}). This ensures budget, mid-market, and luxury properties are equally represented across all three partitions.

  \textbf{The Two Tasks and Tier Balance Rationale}:
  \begin{itemize}
    \item \textbf{Task A (regression)}: Predict the log-price $y = \log(1 + \text{price})$.
    \item \textbf{Task B (classification)}: Classify listings into premium ($1$) or standard ($0$), using the empirical median of $\log(1 + \text{price})$ on the \textbf{training set only} as the threshold ($\tau = 12.2061$, $\approx 200,000$ AZN) to prevent test-set leakage.
  \end{itemize}
  Because upper price outliers were trimmed from the training set, the training median is slightly lower than that of the uncurated full market. Consequently, when this frozen threshold is evaluated on the validation and test sets (where legitimate luxury listings are preserved), the premium class share naturally shifts from $49.4\%$ in train ($31,076$ premium vs $31,846$ standard) to $54.1\%$ in validation ($8,183$ premium vs $6,931$ standard) and $54.2\%$ in test ($8,186$ premium vs $6,928$ standard). This distribution difference is mathematically principled: it reflects strict avoidance of data leakage and tests model generalization against realistic market tails.

  \section{Methodology}

  \subsection{Decision Tree (From Scratch)}
  The tree builds its splits greedily and recursively. For every feature $j$ and every candidate threshold $\theta$, we measure how much the split reduces impurity:
  \begin{equation}
    \Delta I(S, j, \theta) = I(S) - \frac{|S_L|}{|S|} I(S_L) - \frac{|S_R|}{|S|} I(S_R).
  \end{equation}
  Here $S_L = \{(\mathbf{x},y) \in S \mid x_j \le \theta\}$ is the group of samples with $x_j \le \theta$, and $S_R = S \setminus S_L$ is everything else. In other words, we compare the impurity before the split with the weighted impurity of the two groups after it.

  For regression (Task A), the impurity is the mean squared error around the node's mean:
  \begin{equation}
    I_{\text{MSE}}(S) = \frac{1}{|S|}\sum_{i \in S} (y_i - \bar{y}_S)^2, \quad \bar{y}_S = \frac{1}{|S|}\sum_{i \in S} y_i.
  \end{equation}
  For classification (Task B), we implemented two options, where $p_k = \frac{1}{|S|}\sum_{i \in S} \mathbb{I}(y_i = k)$ is the share of samples of class $k$ in the node:
  \begin{align}
    I_{\text{Gini}}(S) &= 1 - \sum_{k=0}^{1} p_k^2, \\
    I_{\text{Entropy}}(S) &= - \sum_{k=0}^{1} p_k \log_2(p_k + \epsilon).
  \end{align}
  A node stops splitting when any of these happens: the depth reaches $d_{\max}$, the node has fewer than $2 \cdot n_{\text{leaf}}$ samples, or a split would leave fewer than $n_{\text{leaf}}$ samples on either side. A leaf predicts the mean $\bar{y}$ for regression, and the class probabilities $[p_0, p_1]$ for classification.

  \subsection{Support Vector Machine with Pegasos (From Scratch)}
  For binary classification with labels $y_i \in \{-1, +1\}$, we minimize the regularized hinge-loss objective:
  \begin{equation}
    J(\mathbf{w}, b) = \frac{\lambda}{2} \|\mathbf{w}\|_2^2 + \frac{1}{n}\sum_{i=1}^{n} \max\big(0, 1 - y_i(\mathbf{w}^\top \mathbf{x}_i + b)\big).
  \end{equation}
  The value $\lambda > 0$ controls the regularization ($C \approx 1/(n\lambda)$). At step $t$ the learning rate is $\eta_t = \frac{1}{\lambda t}$, and we pick one random sample $(\mathbf{x}_t, y_t)$. If it violates the margin, meaning $y_t(\mathbf{w}_t^\top \mathbf{x}_t + b_t) < 1$, we update:
  \begin{align}
    \mathbf{w}_{t+1} &= (1 - \eta_t \lambda)\mathbf{w}_t + \eta_t y_t \mathbf{x}_t, \\
    b_{t+1} &= b_t + \eta_t y_t.
  \end{align}
  Otherwise we only shrink the weights: $\mathbf{w}_{t+1} = (1 - \eta_t \lambda)\mathbf{w}_t$.

  To get non-linear boundaries cheaply, we map the standardized features $\mathbf{x} \in \mathbb{R}^d$ into a $D$-dimensional random Fourier space $\mathbf{z}(\mathbf{x}) \in \mathbb{R}^D$:
  \begin{equation}
    z_j(\mathbf{x}) = \sqrt{\frac{2}{D}} \cos(\mathbf{\omega}_j^\top \mathbf{x} + \beta_j).
  \end{equation}
  The frequencies $\mathbf{\omega}_j$ are drawn from a normal distribution $\mathcal{N}(\mathbf{0}, 2\gamma \mathbf{I})$, and the phase shifts $\beta_j$ are drawn uniformly from $[0, 2\pi]$. This way we avoid building the huge $n \times n$ kernel matrix of the dual SVM.

  \section{Experimental Setup}
  \subsection{Evaluation Metrics}
  All final scores come from the test split that the models never saw ($n = 15,114$):
  \begin{itemize}
    \item \textbf{Task A}: RMSE, MAE, and $R^2$.
    \item \textbf{Task B}: Accuracy, Precision, Recall, Macro $F_1$, ROC-AUC, and PR-AUC.
  \end{itemize}

  \subsection{Hyperparameter Tuning}
  We tuned hyperparameters only on the validation set ($n = 15,114$):
  \begin{itemize}
    \item \textbf{Decision tree}: We swept maximum depth ($d \in [1, 18]$), impurity criteria (Gini vs entropy), and minimum leaf size ($n_{\text{leaf}} \in [1, 100]$). The optimal validated configuration was $\text{criterion} = \text{entropy}$, $d = 12$, and $n_{\text{leaf}} = 10$, reaching validation $F_1 = 0.9204$ and ROC-AUC $= 0.9660$.
    \item \textbf{Pegasos SVM}: We evaluated training epochs ($10, 30, 60$), learning rate scales ($0.5, 1.0, 2.0$), regularization parameter $\lambda \in [10^{-5}, 1.0]$, and RFF kernel scale $\gamma \in [0.1, 10.0]$ with 256 random Fourier components. The best balance was $\lambda = 10^{-4}$ ($C \approx 0.1589$), $\gamma = 0.1$, and 30 epochs, reaching validation $F_1 = 0.8357$, ROC-AUC $= 0.9106$, and margin width $0.1040$.
  \end{itemize}

  \section{Results and Benchmarking}

  \subsection{Do Our Models Match scikit-learn?}
  Table~\ref{tab:results} demonstrates that our from-scratch implementations achieve numerical parity with scikit-learn. On Task A regression, the decision tree RMSE differs by only $0.0010$ ($0.5036$ vs $0.5026$), MAE is identical to four decimals ($0.2495$ vs $0.2493$), and $R^2$ is practically indistinguishable ($0.5992$ vs $0.6007$).   \subsection{Cross-Validation Uncertainty Estimation}
  To confirm that our findings do not depend on a single partition, we conducted 5-fold cross-validation with fold-specific parameter fitting:
  
  \textbf{Decision Tree CV} ($n = 62,922$): Task A regression yields RMSE $0.2719 \pm 0.0083$ (Ours) vs $0.2715 \pm 0.0086$ (scikit-learn) and $R^2 = 0.8059 \pm 0.0085$ vs $0.8064 \pm 0.0088$. Task B classification yields $F_1 = 0.9123 \pm 0.0016$ vs $0.9124 \pm 0.0013$ and ROC-AUC $= 0.9714 \pm 0.0012$ vs $0.9713 \pm 0.0010$. The extremely tight standard deviations ($< 0.002$ in classification) prove that tree parity is stable across folds.

  \textbf{SVM CV} ($n = 78,036$, feature scaling fitted per fold): Pegasos RFF achieves $F_1 = 0.8397 \pm 0.0164$ and ROC-AUC $= 0.9223 \pm 0.0070$. Dual scikit-learn SVC (RBF) attains $F_1 = 0.8874 \pm 0.0052$ and ROC-AUC $= 0.9570 \pm 0.0030$, while linear SGD achieves $F_1 = 0.8286 \pm 0.0086$ and ROC-AUC $= 0.9004 \pm 0.0093$ (Table~\ref{tab:svm_benchmark}). All cross-validation standard deviations remain below $0.017$, verifying consistent ranking capability.

  \subsection{Hyperparameter Sensitivity and Bias--Variance Tradeoff}
  Figure~\ref{fig:tree_depth} illustrates tree depth sensitivity. For deep trees ($d \ge 15$), training ROC-AUC approaches $0.9996$ while validation ROC-AUC degrades to $0.9252$, reflecting memorization of singleton leaves. Enforcing $n_{\text{leaf}} = 10$ at $d = 12$ eliminates isolated leaves, maintaining validation $F_1 = 0.9204$ and lifting validation ROC-AUC to $0.9660$.

  For the Pegasos SVM, sweeping $(\lambda, \gamma)$ shows that heavy regularization ($\lambda \ge 0.1$) over-shrinks the weights ($\|\mathbf{w}\| \to 0$), collapsing validation $F_1$ to $0.0$. The optimal validated setting ($\lambda = 10^{-4}$, $\gamma = 0.1$, 30 epochs) achieves validation $F_1 = 0.8357$, validation ROC-AUC $= 0.9106$, and margin width $0.1040$. On the full training corpus, the converged Pegasos model has $\|\mathbf{w}\| = 41.0717$, geometric margin width $2/\|\mathbf{w}\| = 0.0487$, and $29,853$ margin support vectors ($38.3\%$ of samples).

  \subsection{Error Analysis by Property Type}
  When we split the Task A test predictions by property type, the model works very differently across categories:
  \begin{itemize}
    \item \textbf{Apartments}: Predictions are accurate and consistent for \textit{Yeni tikili} ($n = 8,616$, RMSE $0.218$, $R^2 = 0.838$) and \textit{Köhnə tikili} ($n = 2,753$, RMSE $0.201$, $R^2 = 0.735$).
    \item \textbf{Commercial and land}: Errors are much larger for \textit{Obyekt} ($n = 623$, RMSE $1.256$, $R^2 = 0.062$) and \textit{Torpaq} ($n = 737$, RMSE $1.483$, $R^2 = 0.281$), primarily due to unrecorded attributes such as zoning permits, street frontage, and utility access.
  \end{itemize}

  \section{Discussion and Limitations}
  Our implementations perform close to the scikit-learn baselines, but they have some limits:
  \begin{enumerate}
    \item \textbf{Axis-aligned splits}: A tree can only split along one feature at a time, so it has trouble with diagonal patterns such as price gradients across Baku.
    \item \textbf{Limited random features}: Random Fourier Features allow non-linear boundaries, but $D = 256$ is limited by computing time, so very detailed local price patterns are only approximated.
    \item \textbf{Rare listings}: For luxury properties (above 500,000 AZN) and sparse rural regions (for example Astara and Gədəbəy), there are few examples, so prediction errors are larger.
  \end{enumerate}

  \section{Conclusion}
  We built a recursive decision tree and a primal Pegasos SVM with Random Fourier Features from scratch, and tested them on real-estate data from \texttt{bina.az}. Our decision tree achieves strict numerical parity with scikit-learn ($F_1 = 0.9131$, RMSE $0.5036$ vs $0.5026$). Our Pegasos SVM ($F_1 = 0.8612$, ROC-AUC $0.9282$) outperforms the linear SGD baseline, while offering over $200\times$ faster inference than exact kernel SVC ($0.11$\,s vs $23.86$\,s). Cross-validation uncertainty ($F_1 = 0.9123 \pm 0.0016$ for tree, $0.8397 \pm 0.0164$ for Pegasos) and hyperparameter sweeps confirm stability across folds. Future work will investigate spatial graph embeddings and oblique splits.
